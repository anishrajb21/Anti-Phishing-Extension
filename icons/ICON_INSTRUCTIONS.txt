ICON GENERATION INSTRUCTIONS
============================

You need to create three PNG icon files:
- 16.png (16x16 pixels)
- 48.png (48x48 pixels)  
- 128.png (128x128 pixels)

OPTION 1: Use the HTML Generator (RECOMMENDED)
-----------------------------------------------
1. Open generate_icons.html in your web browser
2. Right-click on each canvas preview  
3. Select "Save image as..."
4. Save as 16.png, 48.png, and 128.png in this icons/ folder

OPTION 2: Use an Online Tool
-----------------------------
Visit: https://www.favicon-generator.org/ or https://www.canva.com/
Create a shield icon with purple/blue gradient
Export as PNG in sizes 16x16, 48x48, and 128x128

OPTION 3: Use Any Image Editor
-------------------------------
Use Photoshop, GIMP, Paint.NET, or any image editor:
1. Create a new image with purple/blue shield design
2. Export/Resize to 16x16, 48x48, and 128x128
3. Save as PNG files with the exact names above

TEMPORARY WORKAROUND:
---------------------
For testing purposes, you can use simple solid color squares.
The extension will work with any PNG files of the correct size.

After creating the icons, delete this instruction file.
